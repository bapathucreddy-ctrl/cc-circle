Read the architecture as it is today

The mobile apps share one Expo / React Native source tree. PostgreSQL RPCs and row-level policies enforce authoritative booking, payment and approval rules. Edge Functions handle privileged provider operations.

Cashfree remains in sandbox. APNs depends on Apple configuration. Instagram connection and admin profile approval are separate badges. Payout eligibility begins 24 hours after both completion and verified payment.

These diagrams use an isolated, source-only snapshot of current local edits, including mobile/src/, admin/src/ and supabase/functions/ / supabase/migrations/. The original repository was not committed or pushed. Snapshot revision: f1e924b9f8eaec77598cf3e05b1c567c2f3dc2b3.

This is a module-and-flow architecture, not an exhaustive column-by-column ERD. Dependency caches, credentials, binary assets and historical build/preview files are excluded. Sources, notes, light/dark themes and motion controls are available inside each Archify diagram.
